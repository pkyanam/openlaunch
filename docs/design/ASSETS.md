# openlaunch image assets

Generated with the built-in imagegen tool on 2026-10-04. The owner selected concept 3, the lowercase `ol` monogram. No final trademark clearance is claimed. Hardware images are illustrative, not wiring references.

- `logo-concepts.png`: four concepts, black on white: open square connector, interlocking ports, lowercase ol, open aperture; small monospace openlaunch wordmarks and numbers. Minimal industrial computing aesthetic, no rockets, sparkles or shields.
- `../../apps/site/public/icon.png`: standalone option 3, bold ring o and upright l with rounded foot, solid black, transparent square canvas, no wordmark.
- `../../apps/site/public/images/uno-r4-wifi.webp`: monochrome studio-style Uno R4 WiFi, three-quarter overhead view; headers, USB-C, barrel jack, LED matrix and board components; white background, subtle shadow, no cables or added labels.
- `../../apps/site/public/images/raspberry-pi-4.webp`: matching monochrome Pi 4 Model B; GPIO header, USB/Ethernet, USB-C and micro HDMI; no case or heatsink.

Hardware PNG outputs were resized and encoded as WebP for delivery. The original generated outputs remain in the local Codex generated-images directory. Website renders all assets and documentation in grayscale. Manufacturer documentation is linked from the resources page.
