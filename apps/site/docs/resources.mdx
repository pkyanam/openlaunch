## openlaunch downloads

Installers are served by openlaunch from the same source commit as the website. GitHub hosts source code and backup copies. The Pi installer downloads a standalone ARM binary and verifies its checksum. Raspberry Pi OS remains the operating system; openlaunch does not provide a flashable OS image.

- [Source ZIP (main)](https://github.com/pkyanam/openlaunch/archive/refs/heads/main.zip) — moving branch; use a commit archive for reproducibility.
- [CI builds and Pi binary artifacts](https://github.com/pkyanam/openlaunch/actions/workflows/ci.yml) — open a successful run and download `openlaunch-pi-binaries`. GitHub sign-in may be required. Build outputs are developer artifacts, not hardware-verified releases.
- [Release page](https://github.com/pkyanam/openlaunch/releases) — future versioned binaries will appear here.
- [R4 provisioning script](/downloads/provision-uno.py) — review it in the checkout, then run `npm run provision:uno`. Do not pipe remote scripts into a shell.
- [Stock firmware source](https://github.com/pkyanam/openlaunch/tree/main/firmware) and [build profiles](https://github.com/pkyanam/openlaunch/blob/main/docs/UNO-R4-PROFILES.md).
- [Pi Go agent and systemd service](https://github.com/pkyanam/openlaunch/tree/main/devices/pi).

[Install the Pi agent](/install-pi.sh), [download the Codex plugin](/downloads/openlaunch-plugin.zip), or [install the local development bridge](/install.sh). For the local bridge, use the [GitHub installer backup](https://raw.githubusercontent.com/pkyanam/openlaunch/main/scripts/install.sh). `/downloads/provision-uno.py` serves the provisioning script directly. Source, CI artifacts and release pages remain linked to GitHub. There is no hosted device token or login needed to read the docs.

## Device and agent SDK

[Download the JavaScript/TypeScript SDK](/downloads/openlaunch-sdk.tgz) or follow the [Device and agent SDK guide](/sdk) for a single-command custom adapter setup. It includes agent API clients and a device client, with typed manifests, action receipts and custom function publishing. The [SDK source](https://github.com/pkyanam/openlaunch/tree/main/packages/sdk) is the backup and reference implementation. Native embedded firmware uses the same [HTTP contract](/api); the maintained Uno adapter is separate from the Node runtime.

## Shared packages

The packages are in the monorepo and are not published to npm yet. See [all package sources](https://github.com/pkyanam/openlaunch/tree/main/packages), including protocol, auth, core, HTTP and MCP. The [architecture guide](/architecture) explains their boundaries.
