openlaunch connects agents to device operations that an owner approves. Pair each device with a short-lived, attach-only `ol_sdk_` setup token; connect agents separately with OAuth or an `ol_agent_` API credential. Then grant functions per device, with an optional expiry or until-revoked access. The Uno R4 WiFi supports health checks, its built-in LED and matrix text. The Pi runtime reports process health. Other boards can connect through a custom adapter or the device HTTP API.

A **device** is a board. An **agent** is software requesting an operation. A **capability** is one operation, such as setting an LED. A **grant** is an owner's permission for one agent to use selected capabilities on one device until a specified expiry.

## Get started

1. [Start the console](/setup).
2. Pair an [Uno R4 WiFi](/uno-r4) or [Pi 4](/pi).
3. [Connect an agent](/agents) and grant health access.
4. Request a health check and inspect the reported result.
