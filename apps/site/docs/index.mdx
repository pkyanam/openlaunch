openlaunch lets an owner pair a device and grant an agent specific capabilities for a bounded lifetime. Shared TypeScript protocol, authorization and command logic connect a local Node/SQLite bridge, React owner console and MCP tools to Go and Arduino clients.

:::warning
Developer alpha. Real hardware operation is not yet verified. Hosted login, OAuth consent and production device controls remain unfinished.
:::

## Start here

- [Local setup](/setup): build the monorepo and run the simulated acceptance flow.
- [Pairing and permissions](/pairing): enroll a device, then separately authorize an agent.
- [Uno R4 WiFi](/uno-r4): stock and repaired console-mux profiles.
- [Raspberry Pi 4](/pi): real process-health runtime.
- [Architecture](/architecture): package boundaries and trust model.
- [Project status](/status): what works and what still needs acceptance.

Local Codex can use the developer MCP endpoint. Public ChatGPT onboarding requires complete hosted authentication first.
